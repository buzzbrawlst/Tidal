About Tidal

Tidal is an OGFN project focused on bringing back the classic Fortnite experience while building a modern, simple and polished way to access it.

What is Tidal?

Tidal is a community-driven OGFN project designed around the classic Fortnite experience. The goal is to create a clean ecosystem where players can access the project through a dedicated launcher, manage their installations and eventually connect to the Tidal game environment.

Our Goal

We're aiming to make the experience feel straightforward from the moment you visit the website to the moment you launch the game. No unnecessary clutter — just a clean launcher, simple downloads and the OG experience.

Community

Tidal is built with the community in mind. The project is intended to grow alongside its players, with new features, improvements and experiences being added over time.

What Tidal is building

🌊 Tidal Launcher A dedicated launcher for managing and starting the project.
⚡ Simple Installation An easy way to get the required files and installations.
🎮 OG Fortnite Experience Built around the classic Fortnite experience and its gameplay.
🔧 Constant Development The project can continue evolving with new systems and improvements.

Project Status

Tidal is currently in development. Some features may not be available yet while the launcher, backend and game infrastructure are being built. More functionality will be introduced as the project develops.

🚧 Tidal is a work in progress.
Features and availability may change as development continues.
